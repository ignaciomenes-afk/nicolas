ACTIVACIÓN DE TU BANDEJA

Activemos tus solicitudes.

Seguí estos tres pasos en tu proyecto de Supabase. La contraseña de tu cuenta se escribe únicamente en Supabase.

  1. 1
    TU CUENTA DE ADMINISTRACIÓN

    Creá tu usuario.

    Abrí el panel de tu proyecto y, en Authentication → Users, elegí Add user → Create new user. Usá tu correo y una contraseña propia. Si aparece Auto Confirm User, dejalo activado.

    Si ya creaste tu cuenta en este proyecto, podés seguir con el paso 2.

    Abrir usuarios de mi proyecto
  2. 2
    PREPARAR Y PEGAR

    Instalá la recepción.

    Escribí el correo de la cuenta que creaste en el paso 1. Vamos a preparar el texto completo para instalar la bandeja y autorizar esa cuenta.

    Este correo se incorpora al texto SQL para que tu cuenta pueda ver las solicitudes.

    Copiá todo, pegalo y ejecutalo.

    1. Tocá Copiar instalación.
    2. Abrí el editor SQL de tu proyecto.
    3. Pegá el texto completo y tocá Run.

    Abrir editor SQL

    El correo se usa solo en esta página y en el SQL que pegues en tu propio proyecto. No se agrega a los enlaces ni se guarda en este navegador.

  3. 3
    YA CASI ESTAMOS

    Comprobá la instalación.

    Cuando el editor muestre que el SQL se ejecutó correctamente, volvé acá y comprobá la recepción. Esta prueba no envía una solicitud de préstamo.
